骑行传动、功率与阻力的数学模型：理论综述修订版

文章定位
采用叙述性理论综述、统一数学推导与可复算算例，不把原创模型或发表新颖性作为前提。
单盘、双盘、多前盘和内变速可共用有效传动比定义；装置差异通过允许档位、效率及换挡约束处理。
正文已加入文献分支对照、通用档位集合、双前盘范围及例子、统一能量平衡与人体供给模型的关系。
引用按研究问题组织，没有将当前检索称作穷尽文献的系统综述。
当前程序仍计算一维非负坡度、正面逆风、固定效率下的力学需求；正文讨论的侧风、下坡制动、变效率和生理模型并未全部实现。

先读什么
1. 初稿.md：摘要和文献脉络说明综述范围；第二、三、五节是传动/阻力/加速理论；第一、八节解释参数依据；第四、六、七节给出数值例子。
2. 计算附录.md：匀加速平均功率、恒功率到达时间、数值校验范围。
3. 模型参数.json：唯一可编辑参数来源。model.total_mass_kg直接填人车装备总质量，不再拆分人重/车重。

初始参考系统：总质量75kg、CdA=0.30m²、Crr=0.004。
与旧稿73kg、CdA=0.32不同，正文、图和数据已一起重算，不能混用旧数值。
质量网格50～120kg、每5kg一档；可改范围、步长和准确总质量。
CdA情景0.26/0.30/0.40；Crr情景0.00291/0.004/0.006。
两组参数中有实测参照、文献取值和敏感性假设，证据性质见正文及JSON的basis/source字段。
不能按车架名称直接匹配某个整个人车CdA，也不能把九种组合当作95%置信区间。

数据文件（初始配置的数据行数，不含表头）
- 巡航功率完整数据.csv：当前参考系统，6坡度×3逆风×46速度，828行。
- 质量分级巡航数据.csv：15总质量×3CdA×3Crr×6坡度×3逆风×46速度，111780行。
- 质量分级爬坡齿比数据.csv：15总质量×3CdA×3Crr×3坡度(6/8/10%)×3功率(150/170/210W)×5前盘，6075行；无风，使用配置中的最大后齿片。
- 常用速度档位数据.csv：5前盘×5速度(25/30/35/40/45km/h)×12后齿片，300行；含踏频区间和升到下一大齿片的踏频跳幅。
- 加速情景数据.csv：20→35km/h的10/15/30秒匀加速，3行。
- 恒功率加速数据.csv：5个恒定功率输入；不可有限时间到达的用时留空并明确状态，不填0。
- 计算参数快照.json：生成数据所用配置的副本；运行不会反过来覆盖模型参数.json。

查表例：先在质量分级巡航数据.csv筛选总质量_kg=75、CdA_m2=0.3、Crr=0.004，再选坡度、逆风和地速。
质量、风阻、滚阻独立组合；总质量不能自动推出CdA，胎压也不能从此表直接推得。
CSV用UTF-8 BOM编码，所有列的单位写在列名。W/kg一律为W/kg人车装备总质量；已删除W/kg骑手。

在PowerShell复算（启动脚本会寻找Python 3.10+；本机已验证3.12）
python .\运行研究.py --mode Check
  只读配置并运行数值检查，不写文件。
python .\运行研究.py --mode Test
  运行独立受力表达式、积分、RK4、边界和配置生效等测试。
python .\运行研究.py --mode Data
  先检查，再生成六个CSV与参数快照；模型本身只依赖标准库。
python .\运行研究.py --mode Figures
  从同一配置生成五张PNG；需要matplotlib。
python .\运行研究.py --mode All
  先运行全部测试，再更新数据、五张图，以及主文摘要/文献脉络/第一/四/六/七/八节、第五节数值、结论和整个计算附录。
  第二、三节的通用扩展及第13～25条参考文献也由脚本维护；原基础推导与前12条文献保留。
  修改这些维护段落时应同步更新更新发布稿.py中的对应文本，以免再次运行时重建覆盖。

也可直接用Python 3.10+运行各个.py。绘图环境缺matplotlib时，在该环境执行python -m pip install matplotlib。
本机默认python和py指向3.4；启动脚本会跳过旧版本。可用环境变量BICYCLE_PYTHON指定完整解释器路径。
准确选好解释器后可使用独立输出目录：python .\复算模型.py --config .\模型参数.json --output-dir .\试算输出
自定义总质量：修改JSON中model.total_mass_kg；分级范围在grid中修改。配置缺字段或参数非法会报错，不静默回退。
